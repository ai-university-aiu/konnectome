PART SEVEN - SIGN-OFF

Three slices, and the same shape ran through all of them: a value that looked like it came from the book, examined until it was clear which page it came from.

Slice 45 refused a duration. The corpus said this kind of switch holds its states for minutes to hours, and that was a sentence about human sleep, not about a generic gate wired into whatever a world happens to want. Refusing it cost the slice its headline number and bought the rule that mattered.

Slice 46 refused a mode name, for exactly the same reason one grain higher. The corpus says the state machinery's flip-flops latch to wake, and konnectome's gate had been validated against the corpus's flip-flop entry, and the line was one line - and it would have set every gate in the repository to the mode of one named flip-flop. The corpus assigns to named individuals. konnectome has kinds. That is the gap, and it now has a number.

And slice 47 found the duration a home by noticing it had never been a duration. Minutes-to-hours against a twenty-four-hour clock is not a length of time. It is a fraction of a cycle. The gate has no cycle and the governor does, and the window turned out to be nobody's number at all: it is the day, read out of the parameters, following them wherever they go.

The best result of the session was one nobody wrote. Slice 45 decided that a window the history does not yet span must be reported as not-yet-measured and never as clean. Two slices later that promise arrived intact in the running machine without a single line arranging for it: no readings, so nothing to re-key, so nothing for the supervisor to judge, so it says what it says when it is told nothing. A property that has to be re-implemented at every join is a convention. A property that falls out is a design, and you only find out which one you built by building the join.

The oldest number in the repository was also finally measured instead of quoted.
