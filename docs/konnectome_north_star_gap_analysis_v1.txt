THE HOMEOSTATIC SCALER CLIPS, AND THE CLIP IS AN IRREVERSIBLE ANNIHILATION.

The corpus states the rule as an imperative. LAYER_04_05_SLOW_VARIABLES_MANUSCRIPT.txt line 3454: "multiply the whole weight vector by one scalar chosen to hit a target, NEVER ADD OR CLIP INDIVIDUAL WEIGHTS, because multiplication alone leaves the relative code untouched." Line 3428: scaling "stabilises the cell without erasing what learning wrote."

packs/plasticity_engine/prolog/plasticity_engine.pl, in plasticity_engine_scale_interface/6:

    RawFactor is 1 + ScalingRate * (Target - Average),
    % The factor floors at zero: a weight can be silenced but never sign-flipped.
    Factor is max(0, RawFactor),
    Weight is Weight0 * Factor

THE COMMENT DESCRIBES THE INTENT CORRECTLY AND THE CODE DOES SOMETHING STRONGER AND WORSE THAN THE INTENT. A factor of exactly zero sets the weight to exactly zero, and because the rule is multiplicative, no later step can ever lift it off zero again. The relative code that the multiplicative form exists to protect is not preserved; it is destroyed.

REPRODUCED, at a scaling rate the pack's own guard expressly permits:

    ?- plasticity_engine_scaling_step(
           [interface(a,b,0.8,1,transmissive), interface(c,b,0.4,1,transmissive)],
           [b-3.0], 0.5, 0.9, Out).
    Out = [interface(a,b,0.0,1,transmissive), interface(c,b,0.0,1,transmissive)].

    % and a subsequent QUIET step, which should regrow them, cannot:
    ?- plasticity_engine_scaling_step(Out, [b-0.0], 0.5, 0.9, Out2).
    Out2 = [interface(a,b,0.0,1,transmissive), interface(c,b,0.0,1,transmissive)].

plasticity_engine_check_scaling_rate/1 bounds the rate to [0,1) and plasticity_engine_check_activity_target/1 refuses a negative target. NEITHER GUARD PREVENTS THIS. The factor goes non-positive whenever the receiving region's average exceeds its target by more than the reciprocal of the rate, which at rate 0.9 is an excess of about 1.11.

WHY 911 GREEN TESTS DID NOT CATCH IT. The capstone runs at rate 0.05 with activations near one, so its factor never approaches zero. The defect is unreachable in every configuration konnectome actually exercises and reachable in configurations it expressly permits. THAT IS THE SAME SHAPE AS THE LAST FOUR SLICES' FINDINGS AND IT IS THE FIFTH IN A ROW: IT WOULD NOT HAVE FAILED.

A SECOND FAULT IN THE SAME PREDICATE, READ RATHER THAN RUN. The scaler runs over every transmissive interface regardless of sign, because konnectome has no sign field. LAYER_04_05_MODES_OUTLINE.txt Entry 18 gives the renormaliser's domain as "every EXCITATORY synapse". The corpus never permits it to touch inhibitory contacts. The edge-type design authority found the missing sign field and reasoned about the fold and the learning rule; IT DID NOT NOTICE THAT THE SCALER IS A SECOND CONSUMER OF THE SIGN IT DOES NOT HAVE.
